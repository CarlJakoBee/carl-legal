Privacy Policy

Carl Assistant — last updated 19 October 2026

1. What this application is

Carl Assistant is a private automation tool operated by a single individual on their own computer. It is not offered to the public, has exactly one user, and is not distributed as a service.

2. What data it accesses

Only with the account owner's explicit consent, and only for the Google account that was authorized, the application may read:

  • Gmail messages — read-only. The application holds no permission to send, delete, move, or label email.
  • Google Calendar events, in order to create and manage appointments on the owner's behalf.
  • Google Drive files, Google Docs, Google Sheets, Google Tasks and Google Contacts belonging to that same account.

3. Where the data is stored

All data remains on the owner's own computer. The OAuth credentials are stored in a local file on that machine and are never transmitted to any server other than Google's own APIs.

4. Sharing

No data is sold, shared, published or transferred to third parties. There is no analytics, no tracking, and no advertising.

5. Retention and deletion

Locally cached data can be deleted at any time by removing the local credential file and application directory. Access can be revoked at any time at myaccount.google.com/permissions.
