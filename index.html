Carl Assistant

A private, single-user automation tool

Carl Assistant is a personal assistant application. It runs locally on its owner's computer and connects only to the owner's own Google account, in order to help organize email, calendar entries, tasks and documents.

It is not a public service. There is no sign-up, no other users, and no third-party access. The application requests access only to the account that its owner explicitly authorizes.

The application reads email in a strictly read-only manner: it cannot send, delete, move or label messages.
